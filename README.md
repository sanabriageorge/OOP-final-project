# OOP-final-project
## Description
A command-line Java application that allows users to create, view, edit, and delete weekly calendar time slots. The system stores schedule data using file storage and includes conflict detection for overlapping time slots.

## How to Run the Program 
1. Clone the repo:
   ```bash
   git clone <repo-url>
   ```
2. Navigate into project folder:
    ```bash
   cd OOP-final-project
     ```
3. Compile all Java files:
   ```bash
   javac *.java
   ```
4. Run the program:
   ```bash
   java MainTerminal
   ```
